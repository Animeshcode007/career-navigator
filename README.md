
# Career Navigator

An intelligent career guidance and path recommendation platform for students.

## Applications

- `frontend/`: React + Vite user interface
- `backend/`: Node.js + Express REST API
- `ml-service/`: Python + Flask recommendation service
- `docs/`: Requirements and technical documentation

## Core workflow

Student profile → Assessment → Career recommendations → Roadmap → Progress tracking

## Development status

Initial requirements and architecture planning.
